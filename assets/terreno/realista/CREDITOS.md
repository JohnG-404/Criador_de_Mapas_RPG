# Créditos dos terrenos

Gerados no SpriteCook: grama, terra, agua, piso-pedra.

Os terrenos abaixo usam texturas do [Poly Haven](https://polyhaven.com), licença **CC0** (domínio público).
Cada uma foi redimensionada para 512 px (repetida 1 ou 2 vezes dentro do quadro para manter o tamanho
das pedras e tábuas coerente com o grid) e teve contraste e saturação ajustados para o estilo "Realista diurno".
Todas continuam emendando sem costura.
