# Arte e fichas dos tokens

Arte: 32 retratos originais vistos de cima, gerados no SpriteCook para o Atlas Board
(arquétipos genéricos, sem personagens, criaturas ou arte de franquias).

Fichas de D&D: os valores das criaturas (PV, CA, deslocamento e nível de desafio) vêm do
System Reference Document 5.1.
